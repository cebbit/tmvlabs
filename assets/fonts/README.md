# Шрифты сайта

Свои файлы вместо Google Fonts: быстрее в России, нет запроса к чужому серверу.

- Dela Gothic One 400: заголовок первого экрана (выбор Максима 19.11.2026).
- Manrope 400..800, вариативный: основной текст.

Подключение: `<link rel="stylesheet" href="/assets/fonts/fonts.css">` плюс `preload` для `dela-gothic-one-cyrillic.woff2`.
Источник: fonts.gstatic.com (Dela Gothic One v19, Manrope v23), наборы cyrillic и latin. Лицензия SIL OFL 1.1, тексты в `OFL-*.txt`.
