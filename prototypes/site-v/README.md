# Весь сайт, 4 варианта дизайна (прототип, 19-20.11.2026)

Открыть: `python3 -m http.server 8765` в корне репо, затем http://localhost:8765/prototypes/site-v/ и листать вниз.
С телефона в той же сети: http://192.168.31.169:8765/prototypes/site-v/

## Варианты (`?v=`)
- `?v=0` «Схема»: линия и узлы, путь заявки как схема (выбран жеребьёвкой Impeccable, ключ 60d4775a).
- `?v=1` «Сутки»: часы идут при прокрутке, блоки привязаны ко времени дня.
- `?v=2` «Переписка»: сайт как диалог в Telegram.
- `?v=3` «Наряд-заказ»: бланки и штампы мастерской.

Первый экран (`prototypes/hero-b/`) и блок услуг (`prototypes/services-b/`) подтягиваются из своих прототипов как есть (fetch + import, без копий). Правки там сразу видны здесь, обратно site-v их не трогает.

## Твики
Панель внизу (на телефоне кнопка «N · Твики»). То же через адрес:
- `?a=0..3` акцент: зелёный, синий, терракота, графит;
- `?g=0..2` фон: тёплый, белый, холодный;
- `?d=0..1` плотность: просторно, плотно;
- `?b2=0..1` 3D-блок услуг выкл/вкл;
- `?gr=0..1` плёночное зерно выкл/вкл.

## Файлы
`index.html`, `boot.js` (сборка страницы, параметры, панель твиков), `render.js` (4 варианта), `content.js` (тексты из `docs/copy/2026-11-18-texts.md`), `screens.js` (макеты экранов кейсов), `style.css`.

## Условности
- Числа с пометкой «сверить» закрашены жёлтой штриховкой: до выката сверить с БД и кабинетами (STATE п.7).
- Экраны кейсов пока HTML-макеты с петлёй 5 с и подписью «макет»; заменить на записи экрана.

## Проверено
Playwright Chromium 1440x900 и 390x844, все 4 варианта: ошибок JS 0, горизонтальной прокрутки нет. Реальные телефоны не проверены.
