# Блок 2 «Экран собирается из блоков» (как igloo, прототип, 19.11.2026)

Открыть: `python3 -m http.server 8765 --bind 127.0.0.1` в корне репо, затем http://127.0.0.1:8765/prototypes/services-b/ и листать вниз.

## Замысел
- Слева заголовок «Что сделаю для твоего бизнеса», полоса из 5 шагов и карточка услуги (тексты из `docs/copy/2026-11-18-texts.md`, п. 2, без цифр с пометкой «сверить»).
- Справа рамка экрана продукта. На каждую услугу свой экран: чат бота, прайс в витрину, TMV Hub, прибыль Valyx, контент-конвейер. Числа внутри экранов показательные, для макета.
- Каждый блок экрана собирается пазлом из плиток (темп hero-b: блок 0,62 с, волна слева направо, плитка 0,26 с с перелётом и щелчком), затем подменяется настоящей вёрсткой.
- При смене услуги те же плитки срываются и перестраиваются в следующий экран; лишние улетают к зрителю, недостающие прилетают издалека.
- Когда экран собран, сцена не рисует (батарея). Без WebGL и при reduced-motion блоки просто проявляются (`ui.js`).

## Файлы
`index.html` (вёрстка экранов, блоки в % рамки, текст в cqw), `ui.js` (прокрутка выбирает шаг, событие `svc-step`), `scene.js` (Three.js, InstancedMesh до 1400 плиток).
