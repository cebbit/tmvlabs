# Логотип TMV Labs (прототип, 4 варианта)
Открыть: `python3 -m http.server 8765` в корне репо, затем http://localhost:8765/prototypes/logo/
Ролик: `demo-logo.mp4`.

1. Сигнал: развитие нынешнего знака (`assets/logo-mark-graphite.png`). TMV одной ломаной, по линии бежит точка-заявка, последний штрих V становится зелёной галочкой.
2. Диалог: облачко сообщения, бот печатает тремя точками, точки становятся галочкой.
3. Матрица: сетка 5 на 5 точек собирает T, M, V и галочку, затем спокойное T с зелёной точкой. В иконке 16 px читается хуже остальных.
4. Блоки: T из двух скруглённых блоков (как плашки первого экрана) и зелёный блок-заявка. Связка со вторым блоком сайта в стиле igloo.

Каждый знак показан крупно с надписью, в шапке, на тёмной и зелёной плашке, в иконке вкладки 32 и 16 px. Надпись: Unbounded 700 + 300. Анимация повторяется раз в 9 с и по нажатию; prefers-reduced-motion: только финальный кадр.
После выбора: чистые SVG-файлы, favicon, аватарка для Telegram и Авито, знак в шапку hero-a.
