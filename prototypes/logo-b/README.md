# Знак TMV Labs из осколков (прототип, 19.11.2026)

Открыть: `python3 -m http.server 8765` в корне репо, затем http://localhost:8765/prototypes/logo-b/ (`?m=word` для слова TMV).
Ролики: `demo-mark.mp4`, `demo-word.mp4`.

Идея: знак и первый экран B одна система. Буква Т собрана из тех же плиток, что заголовок; одна плитка вырвалась и стала перламутровой плашкой сообщения. Смысл: из бизнеса выходит ответ клиенту.

- 3D: плитки слетаются, перламутровая вырывается вперёд и дышит, знак поворачивается за мышью. Материал, свет и тени как в hero-b.
- Файлы: `assets/logo/mark.svg` (светлый фон), `mark-light.svg` (тёмный фон), `favicon.svg` (на тёмной плашке, читается на любой вкладке), `wordmark-tmv.svg` (слово TMV из плиток 5 рядов).
- Сетка знака 3x3, плитка 8,6 из шага 10, скругление 1,9. Перламутр: градиент #6fd3ff, #b59bff, #ffb7d5, #ffe08a, тот же, что перелив букв в hero-b.
- Прежние 4 знака в `prototypes/logo/` (Максим: «простенько») этим вариантом заменяются, если он примет.
